# X 收藏瀑布流

Chrome MV3 扩展，非官方工具，使用当前 Chrome 中已登录的 X 会话读取书签，并保存到插件本地资料库供瀑布流管理和筛选。无需单独给插件做 OAuth 授权。想留存的帖子可以一键下载成 Markdown 笔记，存进你选的文件夹（例如 Obsidian 库），图片和视频一起保存到本地。

![X 收藏瀑布流管理页：按分类筛选、显示浏览量和“已下载”标记的瀑布流卡片](docs/images/screenshot.jpg)

## 同步方式

- **快速读取（默认）**：插件在后台标签页打开 X 书签页，观察 X 网页自己发出的书签列表请求，然后在该页面内用同样的请求逐页翻到底（沿用 X 网页自己的每页条数，页与页之间留有间隔）。不需要滚动页面，一千条收藏大约一分钟读完。请求只发往 X 自己的服务器，使用的就是你浏览器里的登录会话；插件不保存 Cookie 或令牌，也不向任何第三方发送数据。
- **兼容模式（自动兜底）**：如果观察不到书签请求（例如 X 改版），或者翻页无法继续，自动退回滚动页面读取方式补全，速度较慢。
- 每读到一页立即保存。中断、限流或关闭页面都不会丢失已读取的内容，再次点击同步即可继续。
- 同步只会新增或合并记录，按帖子 ID 去重，**不会删除本地数据**。只有弹窗里的“清空本地数据并重建（慎用）”会清空资料库。

## 功能

- 打开弹窗或管理页时自动同步：第一次读取全部收藏，之后只读取新收藏（30 分钟内不重复触发）。每天定时同步默认 01:00，可在弹窗修改或关闭。
- “完整重扫”从头到尾重新读取一遍，用来刷新旧记录的封面、标题和分类。
- 浏览 X 书签页时，页面加载到的收藏也会顺带更新到插件。
- 管理页打开后直接显示本地收藏，分批渲染，几千条也能立即打开；同步过程中显示进度并可随时停止。
- 筛选：关键词（标题、作者、链接，`@名字` 搜作者）、作者（带联想）、发布日期范围、是否含外链，“百万爆款”开关（浏览量超过 100 万，可与任意分类叠加），以及互不重叠的分类：文章、视频、图片、纯文字、无标题。每条收藏只属于一类（没有标题的归“无标题”，其次文章、带视频、带图片，其余是纯文字），各类数量相加等于“全部”，并随其他筛选条件一起变化。点击卡片上的作者可只看该作者。
- 排序：收藏时间（与 X 一致）、发布时间、浏览量、导入时间。按 `/` 聚焦搜索框，`Esc` 清空搜索。
- 每张卡片显示封面、标题、作者、日期和浏览量，点击打开原帖；封面加载失败时自动换用候选图片。
- X 文章单独归类，可用“文章”筛选查看；超过 3,000 字的普通帖子在卡片上标注“长文”。
- 右键卡片（或点卡片右下角的 ⋯）有五个操作：
  - **打开文章**：在新标签页打开原帖。
  - **同步文章**：访问原帖，更新这一条的标题和封面。
  - **编辑文章**：修改标题、添加备注。改过的标题以后同步不会被覆盖；备注会显示在卡片上，也能被搜索到。
  - **下载文章**：临时打开原帖读取正文，转成 Markdown 文件下载（含标题、作者、链接、正文、图片链接和备注）。正文只进下载的文件，不存进插件。读不到正文时，下载只含已保存信息的文件。
    - **下载位置**：第一次下载会询问保存到哪里——选一个文件夹（例如 Obsidian 库里的某个目录）后，以后直接写入该文件夹，不再弹下载框；也可以改用浏览器默认下载。工具栏的「📁 下载位置」按钮随时更换，并可开启「按作者分子文件夹」（如 `alice/标题.md`）。文件夹被移动或权限失效时，会自动改用浏览器下载并提示重新选择。
    - **已下载标记**：下载成功后卡片显示「✓ 已下载」（悬停可看时间和保存位置），工具栏可按「未下载 / 已下载」筛选。再次下载同一篇时会先询问：**覆盖为最新版本**（标题变了也会替换旧文件）、**另存一份**（新文件名加编号）或取消；可勾选「记住我的选择」，之后在「下载位置」里随时改回「每次询问」。右键菜单的「取消已下载标记」只清除标记，不删除文件。
    - **图片和视频**：下载时插件会从 X 加载这条帖子的数据，拿到原图和最高清晰度的 mp4。存到文件夹时默认把图片和视频一起保存到文章旁边的 `assets/<帖子ID>/`，Markdown 改用本地路径（可在「下载位置」里关闭）；某个文件下载失败会保留网络链接并提示。用浏览器下载时只保留网络链接，视频显示为可点击的封面。
    - **笔记属性**：每篇 Markdown 的属性里包括标题、作者、链接、发布时间、保存时间、帖子 ID 和浏览量 `views`（数字，下载时读取最新值，读不到则用同步时的值），可在 Obsidian 里按浏览量排序和筛选。文件名就是文章标题，不带帖子 ID；没有标题时用「作者 日期」。另一篇帖子标题相同时会自动存成 `标题 (2).md`，不会互相覆盖（靠笔记属性里的 `tweet_id` 区分）。
  - **删除文章**：从插件里移除，可立即撤销。X 上的收藏不受影响；之后同步不会把它带回来，除非你在 X 上重新收藏它。
- 已不在 X 收藏夹里的旧记录同步更新不到，打开管理页时会自动逐条访问原帖补全标题。只有图片或视频、没有文字的短帖本来就没有标题，会显示为“无文字”，不再重复尝试。
- 只保存封面链接、标题、备注和筛选所需的元数据，不保存正文。数据保存在当前 Chrome 配置的 IndexedDB 中。

## 安装与升级

1. 打开 `chrome://extensions` 并启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本仓库目录。需要 Chrome 111 或更高版本。
3. **升级时点击扩展卡片上的“重新加载”按钮即可，已有收藏会保留。不要点“移除”——移除扩展会连同本地资料库一起删除。**
5. `manifest.json` 里的 `key` 固定了扩展 ID，所以以后移动或重命名这个文件夹，重新加载后收藏仍然在。
7. 如果插件文件夹里有 `migration/library-backup.json`，第一次打开时会自动导入一次（只补充、不覆盖）。这个文件含有个人收藏，不要提交或分享。
6. 换电脑或迁移：在管理页点“导出备份”得到一个 JSON 文件，在新的安装里点“导入备份”。导入只补充缺少的内容，不会覆盖或删除现有数据；备份不含正文。
4. 升级后如果有已打开的 X 书签页，请刷新一次。

## 使用

1. 在当前 Chrome 配置中正常登录 X。
2. 点击扩展图标或打开管理页，插件会自动开始同步；也可手动点击“同步全部收藏 / 同步新收藏”。
3. 升级前已有的旧记录会在第一次同步时自动补全标题、封面和分类。

读取到列表末尾后，“X 收藏总数”显示本次实际读到的数量。X 上已取消的收藏仍会保留在本地。

## 语言

- 界面有中文和英文两种，按浏览器界面语言自动选择：中文浏览器显示中文，其他语言显示英文。管理页和弹窗右上角的按钮（`EN` / `中文`）可以手动切换，选择会被记住，弹窗和后台提示也跟着变。
- 文字以中文写在代码里，用 `t("…")` 或 ``tr`…${值}…` `` 包起来；英文对照在 `src/i18n-en.js`，以中文原文为键。页面里的固定文字不需要改 HTML，打开时会自动替换。
- 新增或修改文字后运行 `npm test`：缺少英文对照会报错并列出是哪几条。`node scripts/list-i18n-keys.js` 可以列出全部需要翻译的文字。
- 扩展名称和简介在 `_locales/` 里。

## 界面风格

- 配色、圆角和按钮状态集中在 `extension/theme.css`（暖纸色底、森林绿、黄铜色点缀），管理页和弹窗共用，浅色和深色各一套。
- 英文和数字使用随插件打包的 Manrope 字体（`fonts/`，SIL Open Font License，许可文件 `fonts/OFL.txt` 一并打包）；中文使用系统字体。不加载任何远程资源。

## 发布到 Chrome 应用商店

- `npm run package` 生成 `dist/x-bookmarks-grid-<版本>.zip`，只包含运行所需的文件，并去掉 `manifest.json` 里仅供开发用的 `key`。不要直接压缩项目文件夹。
- 商店文案、权限理由、隐私权政策和上架步骤见 `docs/store/`（`listing.md` 中文，`listing-en.md` 英文）。

## 开发

- `npm test` 运行全部测试（Node 内置测试运行器）。
- 与浏览器无关的逻辑在 `src/`：`x-api-parser.js`（解析书签数据）、`library-sync.js`（翻页循环）、`sync-core.js`（合并与同步决策）、`manager-core.js`（筛选排序）。
- `extension/page-hook.js` 运行在 X 页面自身的脚本环境中，`extension/api-bridge.js` 负责与扩展通信，`extension/library-sync-runner.js` 负责调度。
