# Chrome 应用商店上架材料

上传的文件：运行 `npm run package` 生成的 `dist/x-bookmarks-grid-<版本>.zip`。
不要直接压缩整个项目文件夹：里面有个人收藏备份（`migration/`）、测试和 26 MB 用不到的文件。

## 商品详情

**名称**（最多 75 字符）

    X 收藏瀑布流

**简短说明**（最多 132 字符，取自 manifest 的 description）

    非官方工具：把你在 X 上的收藏同步到本地，用瀑布流浏览封面和标题，并按作者、类型、日期筛选。

**详细说明**

    把你在 X（Twitter）上的收藏变成一个可以搜索、筛选、整理的本地资料库。

    ● 一次读完全部收藏：打开插件自动同步，之后只读取新收藏。
    ● 瀑布流浏览：每条收藏显示封面、标题、作者、日期和浏览量。
    ● 筛选不重叠：文章 / 视频 / 图片 / 纯文字 / 无标题，各类数量相加等于总数；可叠加“百万爆款”。
    ● 搜索：标题、作者、链接、备注；@名字 直接搜作者。
    ● 右键操作：打开原帖、同步这一条、编辑标题和备注、下载为 Markdown、从资料库删除（可撤销）。
    ● 下载到你的文件夹：可直接存进 Obsidian 库，图片和视频一起保存到本地；已下载的会标记，重复下载可选择覆盖或另存。
    ● 备份：一键导出 / 导入全部收藏。
    ● 中英文界面：跟随浏览器语言，也可以一键切换。

    隐私：
    ● 所有数据只保存在你自己的浏览器里，不上传到任何服务器，没有统计和广告。
    ● 插件使用你浏览器里已登录的 X 会话读取你自己的收藏，不保存 Cookie 或密码。
    ● 只保存标题、封面链接等信息，不保存帖子正文；下载 Markdown 时正文只写进你下载的文件。

    说明：
    ● 本插件是第三方工具，与 X Corp. 没有关联，也未获其认可。
    ● 需要先在浏览器里登录 X。同步时会在后台临时打开 X 的收藏页，读完自动关闭。
    ● X 改版可能导致同步暂时不可用。

**类别**：工具（Tools）　**语言**：英文为默认语言（文案见 `listing-en.md`），另加中文（简体）。在开发者后台的商品详情页右上角可以切换语言分别填写。名称和简短说明会自动取自安装包里的 `_locales/`。

## 隐私权规范（“隐私权”标签页）

**单一用途说明**

    同步用户自己在 X 上的收藏，并在本地提供瀑布流浏览、搜索、筛选和整理。

**权限理由**

| 权限 | 填写的理由 |
| --- | --- |
| `storage` | 保存同步设置、同步进度和上次同步时间。 |
| `unlimitedStorage` | 收藏资料库保存在本地 IndexedDB 中，收藏多的用户数据量会超过默认配额；申请后也避免浏览器在空间紧张时清掉用户的资料库。 |
| `alarms` | 实现“每天定时同步新收藏”，时间由用户设置，可关闭。 |
| `scripting` | 在插件自己打开的 X 页面里运行读取脚本：读取收藏列表，以及用户主动要求时读取单条帖子的标题或正文。用户下载帖子时，插件只在读取期间、只在 X 帖子页注册一个脚本，从 X 页面自己加载的帖子数据里取出图片、视频地址和浏览量，读完立即注销；脚本不修改页面，也不发送任何数据。 |
| 主机权限 `x.com`、`twitter.com` | 收藏数据只存在于 X 网站。插件需要在 X 的收藏页和帖子页读取用户自己的收藏内容。 |
| 主机权限 `pbs.twimg.com`、`video.twimg.com` | 这是 X 存放图片和视频的服务器。用户下载某条收藏时，插件把这条帖子里的图片和视频一起保存到用户自己选的文件夹，方便离线查看。只在用户点击下载时访问，不访问其他任何网站。 |

**是否使用远程代码**：否。所有代码都在安装包内。

**数据使用**

- 插件读取 X 页面上的内容（网站内容）和用户写的备注，全部只保存在用户本机，不传输给开发者或任何第三方。
- 商店对“收集”的定义是指传出用户设备的数据。按此定义本插件不收集数据，各数据类型可以都不勾选。如果审核提出异议，按要求补勾“网站内容”，并说明仅在本地处理。
- 三项声明都勾选：不出售数据、不用于无关用途、不用于信用评估。

**隐私权政策网址**：必填。把 `privacy-policy.md` 的内容发布到一个公开网址（GitHub Pages、Gist、Notion 公开页面都可以），把网址填进去。发布前把联系邮箱换成你的。

## 上架步骤

1. 注册开发者账号：<https://chrome.google.com/webstore/devconsole>，一次性费用 5 美元，账号需开启两步验证。
2. `npm test` 确认通过，`npm run package` 生成 zip。
3. 在开发者后台“新建内容”上传 zip。
4. 填写上面的商品详情、图片、隐私权规范，以及隐私权政策网址。
5. “分发”里选择公开或不公开（不公开 = 只有拿到链接的人能安装，适合先小范围试用）。
6. 提交审核。申请了网站访问权限的插件通常需要几天，可能更久。

## 需要知道的风险

- **依赖 X 的非公开接口**：插件在 X 页面内重复 X 网页自己的收藏请求。这不在 X 的公开 API 范围内，X 的服务条款限制自动化访问。审核可能因此提问或拒绝；上架后也可能因 X 投诉被下架。类似的收藏导出插件在商店里存在，但没有保证。
- **新增主机权限会重新审核**：这一版新增了 `pbs.twimg.com`、`video.twimg.com`。如果之前的版本已经上架，已安装的用户更新后 Chrome 会提示新权限，用户同意后插件才会重新启用。
- **X 改版会让同步失效**：需要你持续维护并发新版本。发新版本时提高 `manifest.json` 里的 `version` 再打包上传。
- **商店版是另一个插件**：商店会分配新的插件 ID。你自己电脑上从文件夹加载的开发版和商店版数据互不相通，想换用商店版就在开发版里“导出备份”，在商店版里“导入备份”。
- **名称里的 X**：只用于说明用途，说明文字里已注明非官方。如果审核认为有误导，可改成“收藏瀑布流 for X”。
